# Noise Tool

**Try it live:** https://cvd9683-gif.github.io/web-tools/week-2/noise-tool/

A p5.js tool that draws a grid of dots using Perlin noise. You can change the offset, the gap between dots, the two dot colors, the background color, and the shape (circles or squares). The "Auto offset" checkbox animates the pattern, and the Save button downloads the canvas as a PNG.
