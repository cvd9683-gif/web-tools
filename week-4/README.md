# Noise Tool (Week 4 – Flexbox)

**Try it live:** https://cvd9683-gif.github.io/web-tools/week-4/

My p5.js noise tool from week 2, with a new layout built with flexbox. The page is one centered column with lots of white space, round color swatches, and simple lowercase labels. A "+ keep" button adds the current pattern to a gallery below the canvas, so you can see a range of outputs side by side. Click any kept pattern to download it, or use "save" to download the current canvas.

## Inspired by tools from [Everest Pipkin's tools list](https://github.com/everestpipkin/tools-list)

- **[coolors](https://coolors.co/)** – the round palette buttons set all three colors at once, like picking a ready-made color scheme.
- **[pattern mutation](https://lorenschmidt.itch.io/pattern-mutation-tool)** – the "mutate" button changes the pattern a little at random so you can explore variations.
- **[ASCII PAINT](http://ascii.alienmelon.com/)** – the "letters" shape draws the grid with text characters, from light ( `.` ) to heavy ( `@` ).
- **[Contrast Checker](https://webaim.org/resources/contrastchecker/)** – the gray text was darkened so it's readable against the background.
